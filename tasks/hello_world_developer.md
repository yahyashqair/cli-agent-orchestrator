# Hello World Program Task

## Objective
Create a simple "Hello World" program that prints "Hello, World!" to the console.

## Requirements
- Write the program in Python (since this is a Python project)
- The program should be a standalone script
- It should print "Hello, World!" when executed
- Save the file as `hello_world.py` in the root directory of the project

## Acceptance Criteria
- The script runs without errors
- Output is exactly "Hello, World!" (with the comma and exclamation mark)
- Code is clean and follows Python conventions
